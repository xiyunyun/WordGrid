# Skill：WordGrid 单词批量导入格式生成

## 字段格式

每行格式为：

```
单词|音标|词性|词意|笔记
```

字段说明：

| 字段 | 说明                                                         | 必填 |
| ---- | ------------------------------------------------------------ | ---- |
| 单词 | 英语单词                                                     | 是   |
| 音标 | 国际音标，用 `/ /` 包裹                                      | 是   |
| 词性 | 词性缩写带句点，如 `n.` `v.` `adj.` `adv.` 等                | 是   |
| 词意 | 中文释义                                                     | 是   |
| 笔记 | 扩展笔记（谐音、拆解、近似词、反义词、派生词、例句），详见下方笔记规范 | 否   |

## 多词性处理

若单词有两个以上常用词性词意（如 kind 既可作 adj.「友好的」也可作 n.「种类」），需将所有常用词性都写出，**最多不超过三个**。不同词性用 `/` 分隔，对应词意也用 `；` 分隔并保持顺序一致。

```
kind|/kaɪnd/|adj. / n.|友好的；种类|...
```

## 笔记规范

笔记是最后一个字段，内容有固定结构。**笔记中的分号（半角 `;` 或全角 `；`）会被自动转换为换行符**，因此用分号分隔不同段落即可实现换行显示。

标准笔记结构（按顺序，没有的可省略）：

1. **谐音**：帮助记忆的中文谐音，用引号包裹
2. **拆解**：仅当单词为可拆分的复合词时写出。将复合词拆成两个有独立含义的部分，每部分用括号标注其含义，再用 `=` 连接整体释义，说明为什么组合后会得到当前词意。格式：`复合词拆解：part1（含义1）+part2（含义2）=整体释义解释`
3. **近似词**：列出近似词并说明区别
4. **反义词**：如有则写出
5. **派生词**：列出常见派生（动词形式、名词形式、形容词形式等），标注词性和词意
6. **例句**：1-2 个带翻译的例句，每个例句单独用分号分隔（即各占一行）

### 复合词拆解说明

- **适用**：两个独立单词拼接成的新词（如 screenshot = screen + shot）、有明显词根组合的词（如 midnight = mid + night）。包括封闭式复合词（如 keyboard）和开放式复合词（如 ice cream）

### 笔记示例：

#### 单词（screenshot）

```
screen | /ˈskriːnʃɒt/ | n. | 截图 | 谐音："斯克林夏特"；拆解：screen（屏幕内容）+shot（拍摄）=对着屏幕拍一张照片；派生：screenshot(v.)；例句：Take a screenshot of your victory screen.（给你的胜利画面截图。）
```

导入后在笔记弹窗中显示为：

```
谐音："斯克林夏特"
拆解：screen（屏幕内容）+shot（拍摄）=对着屏幕拍一张照片
派生：screenshot(v.)
例句：Take a screenshot of your victory screen.（给你的胜利画面截图。）
```

如果单词带有近似词和反义词，也得写出，但是screenshot没有，所以在这里忽略。

## 注意事项

1. **笔记段落中一行一个单词**：回车换行会被识别为新单词，因此笔记内容中不可使用回车，用分号 `；` 换行。
2. **竖线 `|` 是字段分隔符**：前四个字段（单词/音标/词性/词意）中不可包含 `|`；笔记字段是最后一个字段，其中的 `|` 会被自动拼回（不会丢失）。
3. **分号换行**：仅笔记中半角 `;` 和全角 `；` 都会触发换行，请按段落合理使用。
4. **音标格式**：统一用 `/ /` 包裹，如 `/əˈbændən/`。
5. **词性格式**：带句点，如 `n.` `v.` `adj.` `adv.`；多词性用 `/` 分隔，如 `adj./ n.`。
6. **词意分隔**：同一词性的多个词意用 `；` 分隔；不同词性对应的词意也用 `；` 分隔，顺序与词性一致。
7. **例句翻译**：每个例句后用括号附上中文翻译。
