# Skill：WordGrid 单词批量导入格式生成

## 用途

为 WordGrid 应用生成符合批量导入格式的英语单词列表。每行一个单词，使用竖线 `|` 分隔字段，可直接粘贴到 WordGrid 的「批量导入」文本框中。

## 字段格式

每行格式为：

```
单词|音标|词性|词意|笔记
```

字段说明：

| 字段   | 说明                                                                 | 必填 |
| ------ | -------------------------------------------------------------------- | ---- |
| 单词   | 英语单词                                                             | 是   |
| 音标   | 国际音标，用 `/ /` 包裹                                              | 是   |
| 词性   | 词性缩写带句点，如 `n.` `v.` `adj.` `adv.` `prep.` `conj.`           | 是   |
| 词意   | 中文释义                                                             | 是   |
| 笔记   | 扩展笔记（谐音、近似词、反义词、派生词、例句），详见下方笔记规范     | 否   |

## 多词性处理

若单词有两个以上常用词性词意（如 kind 既可作 adj.「友好的」也可作 n.「种类」），需将所有常用词性都写出，**最多不超过三个**。不同词性用 `/` 分隔，对应词意也用 `；` 分隔并保持顺序一致。

```
kind|/kaɪnd/|adj. / n.|友好的；种类|...
```

## 笔记规范

笔记是最后一个字段，内容有固定结构。**笔记中的分号（半角 `;` 或全角 `；`）会被自动转换为换行符**，因此用分号分隔不同段落即可实现换行显示。

标准笔记结构（按顺序，没有的可省略）：

1. **谐音**：帮助记忆的中文谐音，用引号包裹
2. **近似词**：列出近似词并说明区别
3. **反义词**：如有则写出
4. **派生词**：列出常见派生（动词形式、名词形式、形容词形式等），标注词性和词意
5. **例句**：1-2 个带翻译的例句，每个例句单独用分号分隔（即各占一行）

### 笔记示例

```
谐音："凯的"；近似词：type（作名词时 type 与 kind 同义，但 type 更强调分类，kind 更常用）；反义词：unkind/cruel；派生：kindness(n.)(善良),, kindly(adv.)(善良的)；例句：She is a kind person.（她是个善良的人。）；例句：What kind of music do you like?（你喜欢哪种音乐？）
```

导入后在笔记弹窗中显示为：

```
谐音："凯的"
近似词：type（作名词时 type 与 kind 同义，但 type 更强调分类，kind 更常用）
反义词：unkind/cruel
派生：kindness(n.)(善良), kindly(adv.)(善良的)
例句：She is a kind person.（她是个善良的人。）
例句：What kind of music do you like?（你喜欢哪种音乐？）
```

## 注意事项

1. **笔记段落中一行一个单词**：回车换行会被识别为新单词，因此笔记内容中不可使用回车，用分号 `；` 换行。
2. **竖线 `|` 是字段分隔符**：前四个字段（单词/音标/词性/词意）中不可包含 `|`；笔记字段是最后一个字段，其中的 `|` 会被自动拼回（不会丢失）。
3. **分号换行**：仅笔记中半角 `;` 和全角 `；` 都会触发换行，请按段落合理使用。
4. **音标格式**：统一用 `/ /` 包裹，如 `/əˈbændən/`。
5. **词性格式**：带句点，如 `n.` `v.` `adj.` `adv.`；多词性用 `/` 分隔，如 `adj./ n.`。
6. **词意分隔**：同一词性的多个词意用 `；` 分隔；不同词性对应的词意也用 `；` 分隔，顺序与词性一致。
7. **例句翻译**：每个例句后用括号附上中文翻译。
